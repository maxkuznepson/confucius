# 🔧 Решение проблем с подключением к API

## 📋 Проблема

Приложение не подключается к API серверу или не сохраняет состояние.

---

## ✅ Решение 1: Перезапуск после изменения `.env`

**Важно:** После изменения `.env` нужно **перезапустить dev-сервер**!

```powershell
# 1. Остановить сервер (Ctrl+C)

# 2. Запустить снова
npm run dev
```

Vite кэширует переменные окружения, поэтому без перезапуска изменения не применятся.

---

## ✅ Решение 2: Проверка статуса API

На странице входа теперь отображается индикатор статуса:

- 🔧 **MOCK режим** — жёлтый индикатор (работает с локальными данными)
- ✅ **API режим** — зелёный индикатор (сервер подключён)
- ❌ **Ошибка** — красный индикатор (не удалось подключиться)
- ⏳ **Проверка** — серый индикатор (идёт проверка подключения)

---

## ✅ Решение 3: Сохранение состояния

Теперь приложение **автоматически сохраняет**:
- ✅ Текущий язык (RU/ZH)
- ✅ Тему (светлая/тёмная)
- ✅ Авторизацию (токен)
- ✅ Текущий экран
- ✅ Историю навигации

Данные сохраняются в `localStorage` браузера и восстанавливаются при перезагрузке.

### Очистка состояния (если нужно)

```javascript
// В консоли браузера:
localStorage.clear();
location.reload();
```

## 🔍 Диагностика

### 1. Проверка режима работы

В консоли браузера (F12):

```javascript
// Проверить текущий режим
import('./src/config').then(m => console.log('USE_MOCK:', m.USE_MOCK));
```

### 2. Проверка подключения к API

```javascript
// Проверить health endpoint
fetch('http://localhost:3000/health')
  .then(r => r.json())
  .then(console.log);
```

Должно вернуть:
```json
{
  "status": "ok",
  "timestamp": "2025-...",
  "version": "1.0.0"
}
```

### 3. Проверка localStorage

```javascript
// Посмотреть все сохранённые данные
Object.keys(localStorage)
  .filter(k => k.startsWith('confucius_'))
  .forEach(k => console.log(k, ':', localStorage.getItem(k)));
```

## ❗ Частые проблемы

### Проблема 1: "Режим: MOCK" вместо "API"

**Причина:** `.env` не подхватился

**Решение:**
```powershell
# 1. Проверить .env
type .env

# 2. Убедиться, что VITE_USE_MOCK=false
# 3. Перезапустить npm run dev
```

### Проблема 2: "Ошибка подключения"

**Причина:** API сервер не запущен или недоступен

**Решение:**
```powershell
# 1. Проверить, что API сервер запущен
cd api
npm run dev

# 2. Проверить health endpoint
curl http://localhost:3000/health

# 3. Проверить CORS в api/.env
# CORS_ORIGIN=http://localhost:5173,http://localhost:3000
```

### Проблема 3: Состояние не сохраняется

**Причина:** localStorage заблокирован или очищается

**Решение:**
```javascript
// В консоли браузера:
// 1. Проверить, что localStorage доступен
console.log('localStorage available:', typeof localStorage !== 'undefined');

// 2. Проверить, что данные сохраняются
localStorage.setItem('test', '123');
console.log('Test value:', localStorage.getItem('test'));

// 3. Если не работает — проверить настройки браузера
// (не включён ли режим инкогнито или очистка при закрытии)
```

### Проблема 4: После входа возвращается на Login

**Причина:** Токен не сохраняется или API возвращает ошибку

**Решение:**
```javascript
// В консоли браузера:
// 1. Проверить токен
console.log('Token:', localStorage.getItem('confucius_auth_token'));

// 2. Проверить авторизацию
console.log('Auth:', localStorage.getItem('confucius_auth'));

// 3. Если токен есть, но не работает — очистить и войти снова
localStorage.clear();
location.reload();
```

## 📊 Ожидаемое поведение

### При запуске с API сервером:

1. **Старт приложения:**
   - Индикатор: ⏳ "Проверка подключения..."
   - Через 1-2 секунды: ✅ "Режим: API (сервер подключён)"

2. **Вход:**
   - Ввести `student1@confucius.ru` / `123`
   - Переход на экран ученика
   - Данные загружаются из API

3. **Перезагрузка страницы:**
   - Автоматический вход (токен сохранён)
   - Возврат на тот же экран

### При запуске без API сервера (MOCK):

1. **Старт приложения:**
   - Индикатор: 🔧 "Режим: MOCK (локальные данные)"

2. **Вход:**
   - Ввести `student1@confucius.ru` / `123`
   - Переход на экран ученика
   - Данные загружаются из MOCK

3. **Перезагрузка страницы:**
   - Автоматический вход
   - Возврат на тот же экран
